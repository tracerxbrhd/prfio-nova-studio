Project notes

NOVA Studio is a fictional design-studio portfolio built as an editorial frontend exercise. The featured identities, collaborators and project outcomes belong to the project concept and do not represent commercial client engagements.

Visual material

public/media/velo.webp is an original project-specific image for the fictional VELO case study. The remaining portfolio visuals are local HTML/CSS compositions and interface graphics.

Typography and assets

The site uses system fonts and locally stored interface assets. It does not depend on external font services, stock photography or downloaded icon packs at runtime.

Project brief

The contact area is a browser-side brief builder. Entered information is validated and exported locally; there is no submission endpoint, email delivery, analytics service or persistent storage.

Implementation

Semantic HTML, CSS, vanilla JavaScript and Vite. Interaction includes project filtering, native case-study dialogs, collaborator quote selection, responsive navigation and local brief export.
