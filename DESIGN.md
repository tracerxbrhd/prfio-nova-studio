# NOVA Studio design

## Concept

A bold editorial studio: oversized tightly set sans serif, cobalt emphasis, acid-yellow intermissions, asymmetric paired work and square image frames.

## Palette

Canvas #eff0e9; ink #20221e; cobalt #3156f4; acid #d8ee61.

## Typography

Arial/system sans for headlines and body; Georgia italic for selected phrases; monospace for section indexing. No font CDN.

## Spacing

8px rhythm, 36–112px responsive gutters, 1440px content cap expanding to 1600px on ultrawide displays.

## Shapes

Square portfolio images and ruled rows; circles for directional actions; pill filters indicate selection.

## Animation

0.7s reveals, 0.3s project lifts, short counters and opt-out pointer rotation. Reduced-motion disables decorative movement.

## References

- [Codrops — Grid Item Reveal Animation on Hover](https://tympanus.net/Development/HoverGrid/)
- [Codrops — Line & Letter Hover Animations](https://tympanus.net/Development/LineTypeEffect/)

## Interaction and access

Visible focus, semantic controls, labelled forms and native dialogs preserve keyboard behaviour. Selected controls communicate state through text or pressed state as well as colour. Layouts are exercised at 360, 768, 1440 and 2560 pixels. See QA.md for executed checks.
